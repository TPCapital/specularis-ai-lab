## Resources
### Obsidian

- Link: https://obsidian.md/
- Category: Knowledge Management / Note-taking System
- License: Commercial Product
- Use Case: Build a local-first personal knowledge base for notes, research, frameworks, and long-term archives.
- Strengths: Flexible linking, markdown-based storage, strong plugin ecosystem, and suitable for personal operating systems.
- Limitations: Requires structure and discipline; can become messy without clear taxonomy.
- Relevance to Specularis: Useful as a private knowledge layer connected to public GitHub research indexes.
- Notes: Best used for deeper private notes, while GitHub remains the public-facing archive.
