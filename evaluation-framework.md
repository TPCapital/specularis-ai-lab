# AI Resource Evaluation Framework

A structured framework for evaluating AI tools, agents, coding assistants, browser AI, automation systems, and knowledge management tools.

The goal is to identify AI resources that can improve research, coding, learning, trading workflows, and personal operating systems.

## Evaluation Criteria

| Criteria | Question |
|---|---|
| Source Quality | Is the tool from an official, credible, or well-maintained source? |
| Use Case | What specific problem does it solve? |
| Workflow Fit | Does it fit an existing Specularis workflow? |
| Reliability | Does it produce stable and useful results? |
| Cost | Is it free, paid, API-based, subscription-based, or usage-limited? |
| Privacy | Does it require access to sensitive files, browser data, accounts, or API keys? |
| Integration Potential | Can it connect with GitHub, browser research, trading dashboards, or knowledge systems? |
| Learning Value | Does it teach useful patterns, workflows, or AI system design? |
| Maintenance | Is the product or repository actively maintained? |
| Risk | Could it create security, privacy, cost, or automation risks? |

## Scoring System

Use a simple 1–5 score.

| Score | Meaning |
|---|---|
| 1 | Low value / avoid |
| 2 | Interesting but weak |
| 3 | Useful in limited cases |
| 4 | Strong workflow resource |
| 5 | Core AI infrastructure worth deep study |
