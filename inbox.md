# AI Lab Inbox

Temporary list of AI tools, agents, automation workflows, coding assistants, browser AI tools, and knowledge systems to evaluate.

This inbox is used for resources that may be valuable but have not yet been fully reviewed or classified.

## Workflow

1. Save the resource here first.
2. Check the original source, official documentation, or GitHub repository.
3. Identify its category and use case.
4. Evaluate strengths, limitations, cost, privacy, and integration potential.
5. Move it into the correct category file if it is valuable.
6. Test only when the tool is relevant to an actual workflow.
7. Avoid collecting tools without a clear use case.
